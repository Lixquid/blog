I spend quite a lot of time in the terminal. It's the one unifying interface
that runs under everything else; when you have to go to it to run builds or
open containers anyway, you end up optimizing the time spent by getting good at
navigation, file editing, and inspecting files from it.

That being said! The default terminal and tooling is still a rather barren
place. Most people are still using standardized unix tools and Bash, which was
originally created [in 1989](<https://en.wikipedia.org/wiki/Bash_(Unix_shell)>)!
With close to four decades of software development, there are some improvements
that we can make.

This is a list of common terminal things I do to improve my workflow. They
might not work for everyone, and that's ok! Maybe you'll find some inspiration
for what you want to do!
